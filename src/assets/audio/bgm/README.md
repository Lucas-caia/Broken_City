# Músicas de Fundo (BGM) - Broken City

Coloque aqui os arquivos de música de fundo em formato `.mp3`, `.ogg` ou `.wav`.

### Nomes de Arquivos Suportados:

| Arquivo | Descrição | Comportamento Padrão |
|---|---|---|
| `menu_theme.mp3` | Música tema do Menu Principal e Seleção de Personagens | Se não existir, o jogo gera uma trilha ambiente procedural sombria |
| `combat_theme.mp3` | Música de fundo durante batalhas táticas por cartas | Se não existir, utiliza drone tenso sintetizado |
| `exploration_theme.mp3` | Música de fundo durante a exploração de eventos narrativos | Se não existir, utiliza ambientação procedural sutil |

> **Nota:** O sistema de áudio toca os arquivos em loop contínuo e respeita o volume definido no menu de configurações.
